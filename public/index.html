PROVIDER SETUP

Connect the production pipeline

  1. Create `.env` from `.env.example`.
  2. Add `OPENROUTER_API_KEY` and choose `OPENROUTER_MODEL`.
  3. Restart with `npm run dev`.
  4. Configure image, TTS, FFmpeg, PostgreSQL, Redis, and YouTube before production publishing.

Your keys are only read by the backend; they are never sent to this page.
